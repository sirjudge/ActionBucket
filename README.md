# Description
2d platform fighter built for my friends to have ha ha silly fun time

# Building
## Prerequisites
Rust
more information can be found at [https://rust-lang.org/tools/install/](https://rust-lang.org/tools/install/)
If on linux or unix type system
```shell
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## project building
```shell
cd gameSrc
cargo build
```
