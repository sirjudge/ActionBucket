### What Is a Game Engine?
    - This is the base of what makes making a game possible without having to reinvent the wheel
    - Code someone else wrote to make sprites or models on your screen do something
    - Or in simpler terms, "engine make screen go brr"
### What Is Rust, Why Does It Matter
	- The experts will tell you it's because it's a statically typed thread safe language built for complexity and safety in mind with a tooling rich environment and excellent support for everything from the kernel space to web based technologies.
	- In my case, it does not matter. This is a game I'm building for the love of the game.
### What Is Bevy
	- Rust based game engine
	- Built for code not for a UI, in fact there's no official UI
	- There's decent support for 3rd party UI but support is limited and requires work to update to the latest release
### Why Do It This Way? 
	- Because Bevy was built as a code only engine I am not constrained by the buttons on my screen
	- This is me as an Old man who yells at the cloud
